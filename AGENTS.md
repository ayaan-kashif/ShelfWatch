# ShelfWatch contributor instructions

Read PLAN.md and PROGRESS.md before changes, and update PROGRESS.md after milestones.
Read relevant installed guides in node_modules/next/dist/docs/ before writing Next.js code. This app uses Next.js 16.
Never invent product records, verdicts, scans, charts, rewards or map points. Missing services return explicit unavailable states.
Keep all credentials server-side. Enforce authorization in every protected handler, not only navigation.
Respect reduced motion, keyboard focus, and mobile tap targets.
Work only inside ShelfWatch; the parent directory is a separate existing project.
