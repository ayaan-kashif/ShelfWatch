# ShelfWatch revised design system

Revised after explicit user rejection of the dark mint dashboard. UI/UX Pro Max verification SaaS search returned Hero + Features + CTA, glassmorphism, trust blue and professional geometric sans typography. Adaptation: warm white #f8f9fc, ink #152038, cobalt #2858e5, white cards; dark navy #0c1120, raised #131b2d, periwinkle #8dabff. Semantic success/warning/error colors remain distinct.

Public landing /; consumer overview /dashboard; split-panel login and create account /login. Landing combines large editorial typography, original animated CSS 3D carton, scanning light, orbit, pointer parallax, scroll reveal, explanatory cards, brand feature, FAQs and final CTA. All illustration labels disclose illustration; no made-up results, counts, brands or endorsements.

Theme persists in shelfwatch-theme localStorage and is applied before hydration. Default light. Visible toggle on public and application headers. Reduced-motion preference always wins; artwork has pause/play. 44px touch targets, keyboard focus and accessible mobile drawer.

21st.dev authenticated catalog consulted for animated 3D hero patterns (Festivity Hero, Robot Hero and AI Hero Background). Metadata references only; implementation is original CSS and React.
